## Key Services/Products

### Core Offering
UI Playbook documents **10 UI components** with full specifications:

1. **Tooltip** — Label overlay on hover/focus
2. **Button** — Interactive submit/action element
3. **Select** — Dropdown selection control
4. **Notification** — Toast/alert messaging
5. **TextField** — Text input with label and hint
6. **Avatar** — User identity image (supports image URL, initials, fallback)
7. **Checkbox** — Binary selection control
8. **Motion** — Animation/transitions documentation
9. **Popover** — Floating contextual content
10. **Radio** — Single-selection from multiple options (marked "upcoming")

### Value Proposition
- Centralized specification for UI components
- Accessibility requirements documented
- Best practices and pitfalls documented
- Learns from other design systems' varying implementations
- Free, open-source (MIT license)

## Unique Selling Propositions

1. **Not a component library** — It's a documentation/reference resource (learn from vs. copy)
2. **Opinionated but educational** — Shows what good UI components look like without providing the code to download
3. **Focus on accessibility** — Each component documents a11y requirements
4. **Single author, curated** — Personal project with high quality bar
5. **Community contribution** — CONTRIBUTING.md exists for additions
